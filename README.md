# 💰 Expense Tracker

A beautiful, modern expense tracking application built with Flask. Track your spending, visualize it with charts, and take control of your money.

## ✨ Features

- 👤 User registration and login
- 🔐 Password hashing with bcrypt
- 💸 Add, edit, delete expenses
- 🏷️ 8 categories (Food, Transport, Bills, Shopping, etc.)
- 📅 Date-based filtering
- 📊 Doughnut chart showing spending by category
- 💡 Monthly summary (total, count, all-time)
- 🎨 Modern glassmorphism UI with Bootstrap 5 + Chart.js
- 📱 Fully responsive
- 🛡️ Custom error pages (404, 500)

## 🛠️ Technologies Used

- **Backend:** Flask (Python)
- **Database:** SQLite with SQLAlchemy (aggregations with SUM, GROUP BY)
- **Authentication:** Flask-Bcrypt, Sessions
- **Frontend:** Bootstrap 5, Chart.js, Font Awesome, Plus Jakarta Sans
- **Deployment:** Render
- **Version Control:** Git & GitHub
